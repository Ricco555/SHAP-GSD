# The Gate: SHAP-GSD Consistency Check, Per-Class Results

This file reports, for every (dataset, class) pair in the benchmark, the result of the gate against SHAP-GSD's own attributions described in Section III-A and Section V-B of the accompanying manuscript. The gate is an optional, one-directional consistency check between SHAP-GSD's own attributions and the already-frozen proxy ground-truth profile built from Sources 1, 2, and 3 (dataset documentation, behavioral literature, and structural measurement). It was executed under an explicit researcher assertion that Sources 1, 2, and 3 were frozen for all four datasets, timestamped 2026-09-03T18:24:49+00:00.

A class whose test recall falls below 0.49, the detection threshold established in the manuscript's Discussion (Section VI-C5), receives no consistency claim. Its explained flows are sampled by ground-truth label regardless of the model's prediction, so most would be attributions of a misclassified decision rather than the attack signature under test, and would contaminate rather than test the claim.
